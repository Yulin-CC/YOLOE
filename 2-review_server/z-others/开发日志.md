2. 第二次迭代 [v0.1.1]

    问题点：
        a. 浏览器能开页，提交图片报 POST 400，选了文件却像没带上

           选图后即可进队列

           左栏显示已选体积 vs 上限；超限文案带实际 MB

4. 第四次迭代 [v0.1.3]

    问题点：
        a. 换提示词后框/分数还是上一轮（如 red car → black car 仍画第一轮）
        b. 逗号分隔多个词像无效；有时报 `shape '[1, 66, -1]' is invalid`
    修复：
        a. 根因：YOLOE `set_classes` 不会清 predictor；第一次 `predict()` 把 TPE fuse 进 cls 头
           换词 / 换权重时丢弃模型、重新加载 `.pt`，再 `set_classes` + `get_text_pe`，`predictor = None`
           同词表同权重才复用
        b. 逗号其实已拆开，崩在 fused nc 对不上。`parse_names` 支持 `, ; ，、 /`
           提交后左下角显示实际解析词；默认 conf `0.1`
           改 Python 后需 Ctrl+C 再 `bash 0-build_server.sh`
